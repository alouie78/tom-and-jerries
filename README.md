```
Tom and Jerries is a single-user game where the user (cat) tries to catch as many mice as possible. There are multiple

levels that the user can advance to. This game is similar to whack-a-mole, with the mice periodically disappearing and

reappearing. The user is given a set time to reach a goal number of mice caught (the goal number will increase with each

level and the time limit will decrease with each level). If the user does not reach the goal, the user loses the game.

If the user catches the goal number of mice within the time limit, they are allowed to continue catching mice, accumulating a high score).
```
